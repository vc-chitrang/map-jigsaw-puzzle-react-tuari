# Asset Manifest — what the React + Tauri port must copy

Every asset the running application uses, with its **exact source path** (relative to the Unity
project root) and its **target path** in the React app.

```
UNITY_ROOT = D:/Chitrang_ViitorCloud/R&D/Sliding-Puzzle
```

All source paths below are relative to `UNITY_ROOT`. Target paths are relative to the React app root
(`public/` is served at `/`, so `public/assets/x.png` → `/assets/x.png` at runtime).

Generated by inspecting **GUID references in both scenes** — so this is what is actually used, not
just what exists on disk.

## 1. Fonts (REQUIRED — blocks all UI work)

Copy the **source font files**, not the Unity `.asset` SDF atlases (those are Unity-only, ~32 MB each).
Convert to `woff2` for the web.

| Source | Target | Notes |
|---|---|---|
| `Assets/Games/Sliding-Puzzle/UI/fonts/Conduit ITC Regular.otf` | `public/fonts/ConduitITC-Regular.woff2` | body / regular text |
| `Assets/Games/Sliding-Puzzle/UI/fonts/ConduitITC-Bold.ttf` | `public/fonts/ConduitITC-Bold.woff2` | **all current UI text** |

Convert with `fonttools`:

    pip install fonttools brotli
    fonttools ttLib.woff2 compress -o ConduitITC-Bold.woff2 ConduitITC-Bold.ttf
    fonttools ttLib.woff2 compress -o ConduitITC-Regular.woff2 "Conduit ITC Regular.otf"

> **Licensing:** Conduit ITC is a licensed font. Confirm the licence covers **web/embedded
> (`woff2`) use in a distributed desktop app** before shipping. Same applies to Geometria /
> Leitura News if the brand guide is enforced later.

Also present but **not needed**: `Geometria-Regular SDF.asset`, `Geometria-Bold SDF.asset`
(superseded by Conduit), `LiberationSans SDF.asset` (Unity default — only on deprecated elements).

| `SideStrip.png` | Decorative side strip (landscape) |
| `VerticalLine.png` | 1 px divider |

> `Circle_9Sliced.png` is **9-sliced**. Its Unity border is
> `spriteBorder: {x: 255, y: 255, z: 255, w: 255}` (left, bottom, right, top) — a uniform **255 px**
> inset on all four sides. CSS equivalent:
>
>     .high-score-badge {
>       border-image-source: url('/assets/common/Circle_9Sliced.png');
>       border-image-slice: 255 fill;      /* uniform, keep the centre */
>       border-image-width: 255px;
>       border-style: solid;
>       border-width: 255px;               /* scale down if the badge is smaller than 510px */
>     }
>
> The badge is tinted `#67797F` in Unity. CSS `border-image` cannot be tinted directly — either
> export a pre-tinted PNG or overlay the colour with `background-color` + `mask-image`.

## 9. Copy script

Save as `scripts/copy-assets.ps1` in the React project and run once during setup (or wire it into a
`predev`/`prebuild` npm script).

    # scripts/copy-assets.ps1
    param(
      [string]$UnityRoot = "D:/Chitrang_ViitorCloud/R&D/Sliding-Puzzle",
      [string]$Dest      = "./public/assets"
    )

    $ErrorActionPreference = "Stop"
    $game = Join-Path $UnityRoot "Assets/Games/Sliding-Puzzle"

    $map = @{
      "gameplay" = @(
        "UI/GamePlayScreen/StartButton.png", "UI/GamePlayScreen/StartButton-pressed.png",
        "UI/GamePlayScreen/ResetButton.png", "UI/GamePlayScreen/ResetButton-Pressed.png",
        "UI/GamePlayScreen/PreviewButton.png", "UI/GamePlayScreen/PreviewButton-pressed.png",
        "UI/GamePlayScreen/NewImageButton.png", "UI/GamePlayScreen/NewImageButton-pressed.png",
        "UI/GamePlayScreen/PlayAgainButton.png", "UI/GamePlayScreen/PlayAgainButton-Pressed.png",
        "UI/GamePlayScreen/rotate-right.png", "UI/GamePlayScreen/Group.png",
        "UI/GamePlayScreen/new image icon.png", "UI/GamePlayScreen/TimerBackground.png",
        "UI/GamePlayScreen/HomeButton.png", "UI/GamePlayScreen/BackButton.png",
        "UI/GamePlayScreen/Map Logo.png",
        "UI/GamePlayScreen/0_-1.png", "UI/GamePlayScreen/0_1.png",
        "UI/GamePlayScreen/-1_0.png", "UI/GamePlayScreen/1_0.png"
      )
      "common" = @(
        "UI/Common/Background_Portrait.png", "UI/Common/Background_Landscape.png",
        "UI/Common/Circle_9Sliced.png", "UI/Common/DropDownArrow.png",
        "UI/Common/rotating-arrow-to-the-right.png", "UI/Common/SideStrip.png",
        "UI/Common/VerticalLine.png"
      )
      "select" = @(
        "UI/ImageSelectOrUploadScreen/gallery-add.png",
        "UI/ImageSelectOrUploadScreen/export-arrow-01.png"
      )
      "crop"   = @("UI/CropImageScreen/CropRefrenceFrame.png")
      "browse" = @(
        "UI/MAPCollectionScreen/SearchButton.png", "UI/MAPCollectionScreen/Arrow.png",
        "UI/MAPCollectionScreen/GridView.png", "UI/MAPCollectionScreen/PageSelectionBox.png"
      )
      "qr"       = @("UI/QRScanScreen/QR_Code_1-1024.png")
      "fallback" = @("Textures/image_00.png", "Textures/Image_01.png", "Textures/Image_02.png")
      "fonts-src" = @("UI/fonts/Conduit ITC Regular.otf", "UI/fonts/ConduitITC-Bold.ttf")
    }

    foreach ($group in $map.Keys) {
      $outDir = Join-Path $Dest $group
      New-Item -ItemType Directory -Force -Path $outDir | Out-Null
      foreach ($rel in $map[$group]) {
        $src = Join-Path $game $rel
        if (Test-Path $src) {
          Copy-Item $src -Destination $outDir -Force
        } else {
          Write-Warning "MISSING: $src"
        }
      }
    }

    # popup icons live outside the game folder
    $popupDir = Join-Path $Dest "popup"
    New-Item -ItemType Directory -Force -Path $popupDir | Out-Null
    foreach ($rel in @("Signs/cross.png","Signs/exclamation-mark.png",
                       "Signs/information-button.png","UI/Frame 9.png","UI/Frame 16.png")) {
      $src = Join-Path $UnityRoot "Assets/Modules/PopManager/$rel"
      if (Test-Path $src) { Copy-Item $src -Destination $popupDir -Force }
      else { Write-Warning "MISSING: $src" }
    }

    Write-Host "Assets copied to $Dest"

Run:

    pwsh -File scripts/copy-assets.ps1

Wire into `package.json`:

    "scripts": {
      "copy:assets": "pwsh -File scripts/copy-assets.ps1",
      "predev": "npm run copy:assets",
      "prebuild": "npm run copy:assets"
    }

## 10. Filename hazards (will break a naive copy/import)

| Issue | Files | Fix |
|---|---|---|
| **Spaces** in names | `Map Logo.png`, `new image icon.png`, `Frame 9.png`, `Icons Spritesheet.png` | Rename to kebab-case on copy, or always quote/URL-encode |
| **Inconsistent case** on pressed sprites | `ResetButton-Pressed.png` + `PlayAgainButton-Pressed.png` vs `StartButton-pressed.png`, `PreviewButton-pressed.png`, `NewImageButton-pressed.png` | Normalise to `-pressed` during copy — Windows is case-insensitive, the web is **not** |
| **Typo baked into filename** | `CropRefrenceFrame.png` | Keep as-is or rename consistently |
| **Leading dash** | `-1_0.png` | Quote in shell/scripts; consider `arrow-left.png` etc. |

Recommended normalised names for the port:

    start-button.png / start-button-pressed.png
    reset-button.png / reset-button-pressed.png
    preview-button.png / preview-button-pressed.png
    new-image-button.png / new-image-button-pressed.png
    play-again-button.png / play-again-button-pressed.png
    icon-reset.png (rotate-right) / icon-preview.png (Group) / icon-new-image.png
    map-logo.png / home-button.png / back-button.png / timer-background.png
    arrow-up.png (0_-1) / arrow-down.png (0_1) / arrow-left.png (-1_0) / arrow-right.png (1_0)
    background-portrait.png / background-landscape.png / circle-9sliced.png

If you rename, keep a mapping table in the port repo so future diffs against Unity stay traceable.
